# SafeDream AI 자세 인식 카메라 웹앱

카메라 화면에서 사람의 자세를 인식해 33개 신체 랜드마크와 관절 연결선을 실시간으로 표시합니다.

VS Code에서 실행할 수 있는 카메라 작동 예제입니다.

## 포함 기능

- 카메라 시작 및 종료
- 전면·후면 카메라 전환
- 실시간 관찰 시간 표시
- 현재 카메라 화면 캡처 및 PNG 저장
- PC와 모바일 화면에 대응하는 반응형 디자인

## VS Code에서 실행하는 방법

### 방법 1: Live Server 사용

1. VS Code에서 `safedream-camera-webapp` 폴더를 엽니다.
2. 확장 프로그램에서 `Live Server`를 설치합니다.
3. `index.html`을 마우스 오른쪽 버튼으로 클릭합니다.
4. `Open with Live Server`를 선택합니다.
5. 브라우저에서 카메라 권한을 `허용`합니다.

### 방법 2: Python 서버 사용

VS Code 터미널에서 프로젝트 폴더로 이동한 후 다음 명령을 실행합니다.

```bash
python -m http.server 5500
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:5500
```

## 주의사항

- `index.html` 파일을 더블클릭하여 `file://` 주소로 열면 브라우저 보안 정책에 따라 카메라가 작동하지 않을 수 있습니다.
- 반드시 `localhost` 서버 또는 HTTPS 환경에서 실행하세요.
- Chrome 또는 Edge 최신 버전을 권장합니다.
- 이 예제는 카메라 작동 확인용이며, 발작을 진단하거나 의료적 판단을 제공하지 않습니다.
